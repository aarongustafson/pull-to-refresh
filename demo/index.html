<pull-to-refresh>

Adds a downward pull gesture to scrollable content. Your application handles the refresh event, updates the content, and reports success or failure. See the README for installation and API documentation.

Read the README View on GitHub esm.sh example unpkg example

Each example includes a native Refresh button. With JavaScript it runs the same refresh handler; without enhancement it reloads the document. The component itself does not add a keyboard control.

Basic Example

At the top of the content, pull down and release past the threshold, or use the native Refresh button with a keyboard. This handler generates a number locally; your application would load and validate its own data.

Basic Usage

Keep the existing number visible while loading. Report the outcome in a visible status and call event.detail.complete() in finally, whether the update succeeds or fails. Without JavaScript or registration, the form reloads the document. 

<pull-to-refresh id="demo">
  <div class="demo-content">
    <h3>My Content</h3>
    <p>At the top, pull down and release, or use Refresh.</p>
    <p>Random number: <span id="random">0</span></p>
    <div id="status" role="status">Ready</div>
    <form data-refresh>
      <button type="submit">Refresh</button>
    </form>
    <p>The Refresh button reloads the page if enhancement fails.</p>
  </div>
</pull-to-refresh>
<script type="module">
  import '../define.js';

  const demo = document.getElementById('demo');
  const random = document.getElementById('random');
  const status = document.getElementById('status');
  let pending = false;

  document.querySelector('[data-refresh]').addEventListener('submit', (event) => {
    event.preventDefault();
    if (!pending) demo.triggerRefresh();
  });

  demo.addEventListener('ptr:refresh', async (event) => {
    if (pending) {
      event.detail.complete();
      return;
    }
    pending = true;
    status.textContent = 'Refreshing...';
    try {
      await new Promise((resolve) => setTimeout(resolve, 1500));
      const nextNumber = Math.floor(Math.random() * 1000);
      random.textContent = nextNumber;
      status.textContent = 'Complete! Use Refresh or pull again.';
    } catch {
      status.textContent =
        'Refresh failed. Your previous number is unchanged. Use Refresh to try again.';
    } finally {
      pending = false;
      event.detail.complete();
    }
  });
</script>

Completion ends the component’s interaction, not the application’s work. The component automatically completes after two seconds, even if a handler is still running. Keep a separate loading guard and report success or failure from your handler, not from ptr:refresh-complete. See completion behavior.

Custom Threshold

Set threshold="120" to require a longer pull than the default 80 pixels. Release beyond 120 pixels to trigger refresh.

Using threshold Attribute

You need to pull further down to trigger the refresh.

<pull-to-refresh threshold="120">
  <div class="content">
    <p>Pull beyond 120px to refresh</p>
  </div>
</pull-to-refresh>

Custom Indicator Text

Use your application’s vocabulary in the indicator before translating it. These attributes change one instance; register translations to share messages across instances.

Custom Messages

Here, “check for updates” replaces the default refresh messages. Select “Simulate a failed refresh,” then use Refresh to see the previous number stay visible with a retry message. The next attempt can succeed. 

<pull-to-refresh
  indicator-text="↓ Pull to check for updates"
  release-text="↻ Release to check"
  refreshing-text="⏳ Checking for updates...">
  <div class="content">
    <p>Custom messages</p>
  </div>
</pull-to-refresh>

Disable Text Selection

By default, text selection is allowed during pull gestures. Use the disable-selection attribute to prevent accidental text selection while pulling.

Using disable-selection Attribute

Text selection is blocked during a confirmed pull and restored on release. Try selecting text before and after the gesture. 

<pull-to-refresh disable-selection>
  <div class="content">
    <p>Selection blocked during pull</p>
  </div>
</pull-to-refresh>

Localization (i18n)

Each embedded page declares its language on <html>. The component inherits it; buttons, content, and application status messages are translated separately by the author.

Spanish (Español)

The embedded document uses <html lang="es">. 

<html lang="es">
<pull-to-refresh>
  <div class="content">
    <p>Contenido en español</p>
  </div>
</pull-to-refresh>
